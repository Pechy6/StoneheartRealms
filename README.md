# Stoneheart Realms 

## O projektu 

Stoneheart Realms je simulace správy kolonie, která slouží jako dlouhodobý projekt pro procvičování moderního vývoje webových aplikací v prostředí .NET. Projekt se zaměřuje na návrh architektury, REST API, práci s databází, business logiku a frontend v Reactu.

Projekt slouží především jako prostředek pro zdokonalování mých znalostí vývoje backendových i frontendových aplikací v prostředí .NET.
